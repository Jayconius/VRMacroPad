# Device pictures

Illustrations of headsets, controllers, trackers and base stations, drawn by the author. Copied from the icon pack of the
author's own app OhFudgeMyBatteryChat (`assets/`, MIT licence) and used here as stock images for the SteamVR battery screen.
They were only resized (360 px wide) and trimmed of empty margin; a set (normal + low battery) shares one crop so they line up.
Two file names were tidied: `Controller-3R .png` -> `Controller-3R.png`, `HMD-5LL.png` -> `HMD-5L.png`.

Naming: `HMD-0..5`, `Controller-0..3` + `L`/`R`, `Tracker-0..2`, `Lighthouse-1.0`/`2.0`.
A trailing `L` is the low-battery version (`Controller-0LL` = left controller, low), `DC` on a Lighthouse is "switched off".
